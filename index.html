IEI Gene Hunter

Platform for predicting Inborn Errors of Immunity (IEI) using network embeddings and machine learning on the STRING v11 functional association network.

Ranks 17,283 previously unlabelled STRING v11 proteins by model score. The 1,066 genes used as training labels (414 IUIS-2022 IEI genes, 652 non-immune controls) are excluded from the ranking and shown with their label instead.

Top IEI candidates

Interpreting the model score

The model score is the classifier's raw output and is used for ranking only. It is not calibrated and is not a probability that a gene causes an inborn error of immunity. A small number of genes share identical scores; tied genes receive the same rank.
